# AI-Powered Product Review Intelligence System

An end-to-end Machine Learning NLP application that analyzes product reviews and classifies customer sentiment into **Positive**, **Negative**, or **Neutral**.

## 📌 Features
* **Dataset Size:** 154,475 processed reviews
* **Best Model:** Logistic Regression (~90.27% accuracy)
* **Interactive UI:** Real-time single-review predictor and batch CSV analysis

## 📊 Analytics
* **Positive Reviews:** 122,813
* **Negative Reviews:** 23,353
* **Neutral Reviews:** 8,309
